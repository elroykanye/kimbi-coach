# Kimbi Coach

**Learn it. Defend it. Master it.**

Kimbi Coach is a constructive, persistent accounting study coach for ChatGPT and Codex. It packages eight skills for concept tutoring, hint-led problem solving, verified accounting practice, adaptive quizzes, adversarial mock examinations, assignment review, source-grounded research, and realistic study planning.

## Install

### GitHub marketplace

```bash
codex plugin marketplace add elroykanye/kimbi-coach
codex plugin add kimbi-coach@kimbi-coach
```

Restart the ChatGPT desktop app and begin a new chat after installation.

### ZIP

Download the current package from [Releases](https://github.com/elroykanye/kimbi-coach/releases/latest). The ZIP contains a single top-level `kimbi-coach` plugin directory.

## Source

The plugin is under [`plugins/kimbi-coach`](plugins/kimbi-coach). See its [included skills](plugins/kimbi-coach/README.md) and [installation notes](plugins/kimbi-coach/INSTALL.md).

Kimbi Coach is currently skills-only: it has no remote server, credentials, or independent student-data store.
