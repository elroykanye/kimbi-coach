# Verify an exam answer

Apply the verification gate in [exam verification protocol](references/exam-verification.md) before saying an exam answer is correct, verified, reliable, or trustworthy.

## Required output

Keep the verification visible but proportionate. Include:

1. **Answer or assessment:** the conclusion being checked.
2. **Source basis:** distinguish facts supplied by the question, learner-provided course material, current authoritative external sources, derived calculations, and explicit assumptions.
3. **Independent review:** name the alternative calculation, reconciliation, counterexample, or reasoning check performed.
4. **Remaining limitations:** identify ambiguity, inaccessible sources, uncertain rules, or assumptions that could change the answer.
5. **Confidence label:** `Verified`, `Reasoned but not externally verified`, or `Uncertain` using the criteria in the protocol.

Never fabricate a source, quotation, paragraph number, page, standard, statute, URL, or verification step. A polished explanation is not evidence of correctness. If current tax, law, regulation, or accounting standards matter, verify the jurisdiction and effective period against authoritative current sources before using the `Verified` label.

If verification fails, correct the answer before presenting it and explain the material change. If it cannot be resolved, say so plainly and give the safest next verification action.
