# Accounting practice lab

Create internally consistent exercises that target a stated skill rather than decorative complexity.

## Build the exercise

Determine the topic, level, desired format, number of questions, applicable framework or jurisdiction, and whether answers should initially be hidden. If unspecified, choose a short exercise at moderate difficulty and keep the solution hidden.

For each exercise:

- State all necessary dates, amounts, policies, assumptions, and rounding rules.
- Include only facts that are purposeful; label deliberate distractors when reviewing afterward.
- Compute and independently verify the solution before presenting the problem.
- Ensure linked balances, schedules, journal entries, and statements reconcile.
- Avoid accidentally copying supplied copyrighted questions; create a fresh scenario that tests the same learning objective.

## Run the lab

Present one problem or coherent section at a time. Ask for working, not only the final answer. Grade the method and result separately. Classify each error as conceptual, classification, setup, arithmetic, fact-reading, or communication.

After review, create one altered retry that targets the same weakness without merely changing names. Increase difficulty only after demonstrated mastery. Apply the accounting checks in [coach principles](../../references/coach-principles.md).

When the exercise is exam-like, apply `verify-exam-answer` to the answer key and final evaluation. Trace rules to their source, solve independently, and do not label an answer verified when current authority or a material assumption remains unchecked.
