# Kimbi Coach workspace layout

Create only what the selected storage tool supports. A folder can be represented by a document index when the destination does not expose folders.

```text
Kimbi Coach/
├── KIMBI_PROFILE.md
├── START_HERE.md
├── Courses/
├── Progress/
├── Practice/
├── Research/
├── Submissions/
└── Archive/
```

## File purposes

- `KIMBI_PROFILE.md`: non-secret learning preferences and the workspace locator.
- `START_HERE.md`: current subjects, next actions, and links to important material.
- `Courses/`: syllabus, course-specific notes, and topic maps organized by subject.
- `Progress/`: mastery snapshots and an error log. Do not treat self-reported grades as official records.
- `Practice/`: generated quizzes, worked practice, and retests.
- `Research/`: source maps, annotated bibliographies, and research notes.
- `Submissions/`: learner-owned drafts and review reports. Do not overwrite originals.
- `Archive/`: completed or superseded study material.

Use readable filenames beginning with an ISO date when chronology matters, for example `2026-10-01-inventory-retest.md`. Avoid unnecessary duplicates and preserve source links.
